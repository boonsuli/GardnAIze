# Images pour les expériences Deep Learning

Arborescence locale prévue :

```text
images/
    plants/
        classe_a/
        classe_b/
    gardens/
        jardin_vegetalise/
        jardin_mineral/
        non_exploitable/
```

Les noms sont **illustratifs**, pas des classes garanties par un dataset existant. Chaque sous-dossier doit contenir des photos JPEG/PNG correctement annotées. `plants` concerne les espèces ; `gardens` concerne les scènes de jardin. Ces jeux de données ne sont pas interchangeables.

Avant utilisation, enregistrer pour chaque corpus : URL/version, licence, nombre d'images et classes, définition des annotations, autorisation de redistribution, méthode de dédoublonnage et séparation par source pour limiter les fuites. Ne pas versionner les images brutes ou personnelles dans Git.
